# RSDO Website

Rahma Social Development Organization (RSDO) website.

## Files

- index.html
- style.css
- script.js
- 404.html
- robots.txt
- sitemap.xml
- images/logo.png
- images/cover.png

## Before publishing

1. Replace `YOUR-GITHUB-USERNAME` in `robots.txt` and `sitemap.xml` with the real GitHub username.
2. If more RSDO photographs are available, add them later under `images/` and replace the temporary cover images in the HTML.
3. The contact form currently opens the visitor's email application using `mailto:`. It does not store submissions on a server.
